# Scientific Writing for Research - IEEE Conference Paper Project

This repository contains the IEEE conference LaTeX project set up for the **Scientific Writing for Research** course at Politehnica University of Timișoara (UPT).

- `IEEE_Conference_Paper.pdf`: Pre-compiled verification PDF.
- `main_IEEEtran.tex`: Standard IEEE conference class file template (`IEEEtran.cls`).
- `IEEE_Conference_Paper.tex`: Self-contained standalone compilation file.
- `references.bib`: BibTeX database file.
